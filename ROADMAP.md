**Last reconciled: 2026-09-22.** Based on merged code, the closed bilingual issue #178, and the founder’s final live review. Runtime flags and live corpus counts were not re-queried for this documentation update.

**Status:** `[x]` delivered/completed · `[~]` partially complete or validation still open · `[ ]` not delivered (paused items are called out explicitly). These markers describe work status, not deployment branches.

The real UX evolved past the original day-by-day spec in places — see "Added scope" below. This file tracks both the official D-items and where the actual build diverged from them.

- [x] **Searching, Mirror, Gratitude — three more screens, discovered 2026-07-12, built 2026-07-13.** Real mockups (`refugio-all-screens.html`, `bocetos_pantallas_05_06_08.html`, `refugio_spec_design_v3.png`) revealed the flow is actually **8 screens**, not 5: Arrive → Observe → Remember → Write → **Searching** → **Mirror** → **Gratitude** → Leave a Trace.
  - **Searching** (`src/app/[locale]/(experience)/write/_components/searching.tsx`) — not a separate route; a full-screen ritualized loading state (gold sonar rings + orbiting particles) shown while `POST /api/entries` is in flight.
  - **Mirror** (`/mirror`) — violet "other" node, quote reveals letter-by-letter. Reached on `no_match` too, not just `matched` — the node dims rather than the visitor dead-ending in Write. Follow-up adjustment pass resolved 2026-07-27: matched-branch tagline/subcopy rewritten to stop presuming the visitor's own feelings, matching the design brief's evidence-not-persuasion principle. **Split into two signals 2026-08-02** (see the Resonate entry below): "this resonated with me" is now a one-shot tap into `phrase_resonances` — the same table and phrase Observe's resonate button feeds, so a tap here counts toward the public count shown in Observe too — and "I would love to connect" is a separate toggle that took over `responses.wants_reply`, now actually meaning what its column name always said. **No-match copy corrected 2026-08-03** (PR #152): the previous copy implied things the system can't actually verify — a future or already-existing connection — when entries only ever get compared against the `phrases` corpus, never against each other. Subcopy rewritten to state the corpus's real limit instead ("Nothing echoed back this time..."), and the no-match box got the same violet-glow/letter-reveal treatment already used on the matched branch and Observe's tooltips.
  - **Gratitude** (`/gratitude`) — static closing message, densest/warmest ecosystem visual (Arrive's particle pattern + Observe's full multicolor palette), no input. Follow-up adjustment pass resolved 2026-07-27: tagline/subcopy no longer claim closure or preview Leave a Trace's own reveal ahead of time.
  - Write itself did *not* get the violet-accent-canvas visual update the same mockups implied — still open if picked back up later.
- [x] **Home (screen 0), built 2026-07-14.** `/` used to be the bare create-next-app boilerplate — now a real screen inside `(experience)`, inheriting the shared dark layout. Sourced from a second ChatGPT design conversation (PDF), arguing Home shouldn't *explain* Refugio but let a visitor *feel* it in a few seconds — same thesis as the Toy Story/Bonnie analysis behind the rest of the flow. Shows real excerpted phrases (≤6 words) from the live `phrases` corpus, fading in and out, instead of description copy. Carries the mandatory rules-disclosure modal (see the non-negotiable checklist).
- [x] **Readability and cold-arrival orientation** — fluid typography shipped in PR #170 (2026-08-19). PR #177 added a three-part, visitor-paced introduction on Home (promise → mechanism → human evidence), shown after rules acknowledgment and remembered per browser. Both now use bilingual catalogs. Implementation is complete; whether the introduction resolves confusion for cold arrivals remains unvalidated.
- [x] **Write/Leave a Trace prompt copy + shared `ScreenPrompt` typography, built 2026-07-14.** Both screens lacked invitation copy above their input. Extracted a shared `ScreenPrompt` component so Arrive, Remember, Write, Gratitude, and Leave a Trace all inherit one typography scale instead of each re-declaring its own.
- [x] **Observe arrival transition, built 2026-07-15.** `/observe` used to fetch its data and compute an O(n²) similarity matrix inline in a blocking Server Component — the wait after tapping "entrar" in Arrive scaled with corpus size and had no failure handling. Replaced with a client-driven flow: a ritual transition (gold sphere → breathes → becomes a star → travels → holds) always plays to completion regardless of fetch timing, and a fetch failure falls through to a static guided-breathing screen with silent background retry instead of a blank page. The O(n²) computation itself is untouched — not worth optimizing before there's real data volume, same call as `match_phrase` below.
- [x] **`/contribute` standalone seed page, built 2026-07-15.** A direct link for workshop podmates to seed the corpus without sitting through the full 9-screen flow — states what Refugio is, the "no tags, no signatures" brief, and a soft prompt (emotions from working with AI) in case someone's stuck. Loops back after each submit instead of resolving to a close screen, since contributors are expected to leave several. The `contribute_open` flag allows access while the main site is closed. With that flag off, Contribute follows `site_public`; it is still reachable when the main site is open. Both flags are controlled from `/admin`.
- [x] **Site-visibility feature flag (maintenance mode), built 2026-07-14.** First flag on a new generic `settings` key-value table (deny-by-default RLS, same as every other table). `site_public`, admin-controlled from the dashboard header, gates every public route in `proxy.ts` — off redirects to `/closed`; `/admin` and `/api/cron` stay reachable regardless. The app-level, Vercel-free-tier-friendly alternative to Vercel's own preview-only password protection, which `master` can't use. **Scoped per environment** (`site_public:production`, `site_public:preview`, `site_public:development`) after finding the naive first version used one global row shared across all three, because the environments originally shared a Supabase project — closing any one environment would have closed all of them. Local development now defaults to a separate local Supabase stack. **`site_public:production` was seeded to `false` directly in Supabase before the D14 promotion**, and confirmed closed by hand afterward — production did not launch open to the public.

Decision: keep the write path and the toggle (near-zero cost, and it gives the visitor a real interaction moment independent of whether anyone ever looks at the data) — same reasoning as the D27-28 completion-rate descope, no dashboard is worth building for a ~10-user MVP; query `responses.wants_reply` directly by SQL if the number is ever needed for demo day or interviews.
- [x] **D17 Leave a phrase** — "Leave a Trace", screen 09 of 9 (counting Home), the last in the sequence. `/leave-a-trace`, optional (400 chars as of 2026-08-02 — raised from 120, which was cutting off real submissions mid-thought; PR #144 — explicit "I'd rather not leave anything" skip), submits via `POST /api/phrases`.
  - **Post-hoc fix:** `finalizeUserPhraseModeration` was activating approved user phrases without ever computing an embedding (`active=true`, `embedding=NULL`), which would have 500'd `/observe` for every visitor the moment the first user phrase got approved. Fixed before shipping: activation only happens in the same write that computes a real embedding. Observe also got a defensive filter dropping any active-but-embedding-less row.
  - **Moderation policy:** submissions remain inactive after automated moderation. A human activates an approved phrase in `/admin/phrases`; activation ensures an embedding exists. This applies to both Leave a Trace and Contribute. The earlier automatic-publication policy was superseded in July.
