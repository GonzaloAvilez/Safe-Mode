Return key ritual · Option C (the mix)

Design reference for ADR-004 #212, step 3: the Leave a Trace author who chooses to receive letters. Click the buttons inside the screens to walk the flow; the target screen is highlighted. UI copy is the product's Spanish copy.

Flow

  1. C1 · Choose after letting go. The choice is its own moment after the trace is left, never mixed with writing (from B). "Así está bien" goes to today's closing, without the seal line.
  2. C2 · Your seal. The three lights (one per group of five digits) above the private card: gift sentence, seal, QR inside a postage stamp ("sello" means both seal and postage stamp).
  3. C3 · Seal it. The card closes as an envelope and asks for one randomly chosen group (from A); the unlit light marks which one. C3b is the alternative for the same step: no envelope, "light the missing light".
  4. C4 · Closing. Today's closing plus "Si alguien te escribe, tu sello abrirá su carta."

Constraints

  • The QR here is illustrative. The real one encodes only the 15 digits, never a URL, and keeps its light field and quiet zone: no ornament touches it.
  • The seal lives only in memory on this screen: never in the URL or browser storage. It survives a locale switch, not a reload.
  • Sealing calls POST /api/return-key/confirm with the full seal; only then does the phrase accept letters (#245, #246).
  • No share button: saving is a PNG download, plus "Lo anoté a mano".

Still open (discussed, not decided)

  • C3 (envelope) or C3b (light the missing light).
  • Require the save action before continuing (the action can be required, the saved file can't be verified); "Volver a ver mi sello" then asks for a different group; always an exit, "Mejor sin cartas".
  • Make sealing the closing itself: lighting the last light triggers "Tu presencia ahora también forma parte de este ecosistema", so the required steps don't break the closing.
  • C1 sends the phrase when the person answers: closing the tab at that question loses the trace, unless the phrase is saved first and the letters choice is attached afterwards (a server change).
